## The entry

Exactly one word: the single word grandma would text about AI.

**`witchcraft`**

Grandma's verdict on AI: it must be magic. Warm, baffled, funny with zero
context — and far fresher than the obvious picks.

## How it works

`main.py` (pure Python stdlib, deterministic, no network) writes that one word
to `/output/entry.txt`. See `CANDIDATES.md` for the 20 candidate words drafted
in-session and why `witchcraft` won over the first pick, `robit`.
